# Electronic Shop

A multi-page website for an electronics store, with a products catalogue for phones, laptops, smartwatches and headphones. This was my **first project**, built with plain HTML and CSS.

## Features

- Home, Products, About and Contact pages with a shared look and navigation
- Product catalogue with an image for each item across four categories:
  - Smartphones
  - Laptops
  - Smartwatches
  - Headphones and earphones
- Simple, clean styling in a single stylesheet

## Project structure

```
.
├── index.html       # Home page
├── products.html    # Product listings
├── about.html       # About the shop
├── contact.html     # Contact page
├── style.css        # Styles for all pages
└── *.jpg / *.png    # Product and banner images
```

## Run locally

No installation is needed.

```bash
git clone https://github.com/adars-h2007/Electronic-Shop.git
cd Electronic-Shop
```

Then open `index.html` in your browser.

## Tech used

- HTML5
- CSS3

## What I learned

- Structuring a multi-page static website
- Linking pages together with consistent navigation
- Styling a layout with CSS and working with images
